# Site Canil Marley Kiara

Arquivos: index.html, style.css, script.js e a pasta images/.
Abra o index.html no navegador (precisa de internet para carregar as fontes do Google Fonts: Playfair Display, Dancing Script e Lato).

## Como hospedar
Envie a pasta inteira (index.html, as demais .html, .css, .js e a pasta images/) para qualquer hospedagem de site estatico (Netlify, Vercel, GitHub Pages, Hostinger etc.). O arquivo principal e o index.html. Precisa de internet apenas para carregar as fontes do Google Fonts.

## Galeria
Para adicionar fotos, copie uma linha `<div><img src="images/galeria/NOME.jpg" alt="Filhote"></div>` dentro da `.track` no index.html. Clicar na foto abre ela ampliada.
